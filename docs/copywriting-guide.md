# 文面作成の手順書 (AIで案を作る)

要件定義書 F3「文面案はAIで作成する。業界の課題を調べ、切り口ごとに案を出す手順書」に対応する。

## 1. 先に決めること

- 送る相手の業種 (解体工事業 / 石綿除去業 / 産業廃棄物処理業) — 業種ごとにキャンペーンかタグを分けると比べやすい
- 読んだ人にしてほしい行動を1つだけ (例: 「サンプル請求」「価格表のダウンロード」「返信で見積依頼」)
- リンク先 (商品ページ・問い合わせページ) のURL

## 2. 業界の課題を調べる (事実確認は必ず一次情報で)

切り口の候補 (これをそのまま本文に書かず、**環境省・厚生労働省・都道府県の公式資料で内容と施行日を確認してから** 使う):

| 切り口 | 相手が気にしていること (例) | 確認先の例 |
|---|---|---|
| 事前調査の義務化 | 解体・改修前の石綿含有の事前調査と結果報告、有資格者による調査 | 厚生労働省・環境省「石綿総合情報ポータルサイト」、大気汚染防止法・石綿障害予防規則 |
| 廃棄時の梱包・表示 | 廃石綿等・石綿含有産業廃棄物の梱包方法 (二重梱包など)・表示、運搬中の飛散防止 | 環境省「石綿含有廃棄物等処理マニュアル」、廃棄物処理法施行規則 |
| 現場の手間・コスト | 袋の破れ・作業時間・保管スペース・在庫切れ | 自社の顧客の声・営業担当のヒアリング |
| 元請・発注者からの要求 | 写真記録・マニフェスト・作業計画との整合 | 取引先の声 |

## 3. AI への依頼文 (コピーして使う)

```
あなたは法人向けB2Bメールのコピーライターです。
次の条件で、営業メールの件名と本文を「切り口」ごとに3案作ってください。

# 商材
アスベスト(石綿)廃棄物用の袋などの関連資材 (商品の特徴: ここに3〜5行で書く)

# 送る相手
{業種} の会社の担当者 (例: 解体工事業の現場責任者・購買担当)

# 切り口
1. {例: 廃棄時の梱包基準への対応}
2. {例: 現場の作業効率・袋の破れ対策}
3. {例: 急ぎの調達・在庫}

# 守ること
- 件名は25〜35文字。「Re:」「Fw:」「【重要】」「至急」は使わない。誇張 (絶対・100%・業界No.1 等の根拠のない表現) を使わない
- 本文はテキストのみで300〜450文字。最初の2行で「なぜあなたに送ったか」と「何の案内か」が分かるようにする
- 法令の内容は断定せず、「〜が求められています (詳しくは〇〇をご確認ください)」程度にとどめる
- してほしい行動は1つだけ: {例: サンプル請求のページを見る}
- 差し込み項目として {{会社名}} と {{担当者名|ご担当者}} を使う
- 送信者情報・配信停止の案内は自動で付くので本文に書かない

# 出力
案ごとに「切り口 / 件名 / 本文」
```

## 4. 案を選んで登録する

1. AI の案を読み、**事実と違う・言い過ぎの箇所を直す** (法令の名前・施行日・数値は必ず確認)
2. 2〜3案を選び、キャンペーンの初回テンプレートとしてパターン A・B・C で登録する
   - 1回に比べるのは「件名」か「切り口」のどちらか一方だけにすると、何が効いたか分かる
3. 管理画面の「プレビュー」で、差し込みと末尾の法定表示を確認する
4. 社内アドレスにテスト送信し、スマートフォンでも読みやすいか確認する

## 5. 結果を見て次に活かす

- A/B テストは自動で決定される (各パターン既定200件、またはウォームアップ段階3に入った時点)。点数は 返信 > クリック > 開封 の順に重く、苦情・配信停止は減点
- 決まったパターンと点数は管理者にメールで届く。次のキャンペーンでは勝ちパターンを基準に、別の切り口を1つ足して比べる
- 苦情・配信停止が多い文面は、内容が良くても使わない

## 禁止事項 (保存時に一部は自動でチェックされる)

- 返信・転送を装った件名 (「Re:」「Fw:」)
- 請求・注文・当選などを装う件名、根拠のない誇大表現
- 送信者を偽る、または分かりにくくする表現
