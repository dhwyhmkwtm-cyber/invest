# 03. 作成・導入手順（Step 3）

ショートカット本体は署名済みファイルとして配布できない（`01_feasibility.md` #11）ため、iPhone のショートカットアプリで組み立てる。所要時間は30〜45分程度。

- 対象: iOS 17 / 18 以降（日本語表示）。アクション名は iOS のバージョンにより多少異なる。見つからない場合はアクション検索で英語名（括弧内）でも探せる。
- 手順番号（A-1 など）はテスト手順・不具合報告で共通に使う。
- 「→ 変数『◯◯』」は、直後に **「変数を設定」** アクションを追加して変数名を◯◯にする、という意味。
- 正規表現・貼り付け用テキストは **コードブロックの内容をそのままコピー** すること（全角/半角の違いに注意）。

---

## 0. 事前準備（データファイルの配置）

### 0-1. データファイルを iPhone に置く

`data/messages.json` を iPhone の **ファイルアプリ → このiPhone内 → 配達メッセージ**（フォルダを新規作成）に `messages.json` という名前で保存する。方法は次のいずれか。

| 方法 | 手順 |
|---|---|
| A. AirDrop / メール添付 | PC から送信 → iPhone で「"ファイル"に保存」→ 上記フォルダを選択 |
| B. GitHub から | Safari でリポジトリの `data/messages.json` を開き「Raw」→ 共有 →「"ファイル"に保存」（非公開リポジトリの場合はログインが必要） |
| C. iPhone だけで（取込用ショートカット） | 下記 0-2 の補助ショートカットを作り、JSON 本文をコピーして実行 |

> 保存先を iCloud Drive にしない理由: iCloud Drive 上のファイルは端末容量の状況で本体から退避され、オフライン時に読めなくなることがある。iCloud Drive を使う場合は、ファイルを長押し →「ダウンロードしたままにする」を設定すること（iOS 18 以降）。

### 0-2. （任意）補助ショートカット「配達メッセージ取込」

クリップボードの JSON を検証してファイルに保存する。

1. **クリップボードを取得**（Get Clipboard）
2. **入力から辞書を取得**（Get Dictionary from Input）
3. **辞書の値を取得**（Get Dictionary Value）: キー `schemaVersion`
4. **if文**（If）: 辞書の値 **が次と等しくない** `1`
   - **アラートを表示**（Show Alert）:「JSONとして読み込めないか、schemaVersionが1ではありません」
   - **このショートカットを停止**（Stop This Shortcut）
   - **if文の終了**
5. **ファイルを保存**（Save File）: 入力 = 手順1の「クリップボード」、保存先 = このiPhone内/配達メッセージ、ファイル名を `messages.json` に設定する方法として、手順1の直後に **名前を設定**（Set Name）で `messages.json` を付けておく。「保存先を尋ねる」はオフ、「上書き」をオン。
6. **通知を表示**（Show Notification）:「データを取り込みました」

> 保存先フォルダの指定・上書きの挙動は iOS バージョン差があるため実機で確認する（テスト T-30）。

## 1. ショートカット「配達メッセージ」の作成

ショートカットアプリ →「＋」→ 名前を **配達メッセージ** にする。以下のアクションを上から順に追加する。

### A. データの読み込み

| No. | アクション | 設定 |
|---|---|---|
| A-1 | **ファイル**（File） | 「ファイル」をタップ → このiPhone内/配達メッセージ/messages.json を選択 |
| A-2 | **入力から辞書を取得**（Get Dictionary from Input） | 入力 = ファイル |
| A-3 | **変数を設定** | 変数名 `データ` |
| A-4 | **辞書の値を取得** | 値 / キー `schemaVersion` / 辞書 = `データ` |
| A-5 | **if文** | 辞書の値 **が次と等しくない** `1` |
| A-5a | └ **アラートを表示** | 「データを読み込めないか、形式が対応していません。ファイルアプリの 配達メッセージ/messages.json を確認してください。」 |
| A-5b | └ **このショートカットを停止** | |
| A-5c | **if文の終了**（「その他の場合」は削除してよい） | |
| A-6 | **辞書の値を取得** | キー `messages` / 辞書 = `データ` |
| A-7 | **変数を設定** | `一覧` |

> A-1 で「ファイル」アクションが使えない場合の代替: **フォルダからファイルを取得**（Get File from Folder）でフォルダ = このiPhone内/配達メッセージ、パス = `messages.json`、「見つからない場合にエラー」オン。

N4（前後の句読点）:
```
^[。、．.,，!！?？]+|[。、．.,，!！?？]+$
```

### D. 番号の判定

| No. | アクション | 設定 |
|---|---|---|
| D-1 | **何もしない**（Nothing） | |
| D-2 | **変数を設定** | `番号語`（空にしておく） |
| D-3 | **テキストを照合**（Match Text） | パターン（下記N5）/ テキスト = `検索語` |
| D-4 | **if文** | 照合結果 **値がある** |
| D-4a | └ **照合したテキストのグループを取得**（Get Group from Matched Text） | インデックス `1` のグループ |
| D-4b | └ **変数を設定** | `番号語` |
| D-4c | └ **辞書の値を取得** | キー `kanji` / 辞書 = `正規化表` → 変数 `漢数字表` |
| D-4d | └ **辞書の値を取得** | すべてのキー / 辞書 = `漢数字表` |
| D-4e | └ **各項目を繰り返す** | C-9a〜C-9c と同じ（`全角表`→`漢数字表`、`検索語`→`番号語` に読み替え） |
| D-4f | └ **テキストを置き換える** ×4 | 対象 `番号語`、正規表現オン、下記「十」規則を**この順に**。各置換の後に変数 `番号語` を設定 |
| D-4g | └ **テキストを照合** | パターン `^[0-9]+$` / テキスト = `番号語` |
| D-4h | └ **if文** | 照合結果 **値がある** |
| D-4i | 　└ **テキストを置き換える** | 検索 `^0+(?=[0-9])` / 置換 空欄 / 正規表現 オン → 変数 `番号語` |
| D-4j | 　**その他の場合** → **何もしない** → 変数 `番号語`（番号ではないので空に戻す） | |
| D-4k | 　**if文の終了** | |
| D-5 | **if文の終了** | |

N5（番号の形）:
```
^(?:番号)?([0-9〇零一二三四五六七八九十]+)(?:番目|番|ばんめ|ばん)?$
```

「十」規則（検索 → 置換）:

| 順 | 検索 | 置換 | 例 |
|---|---|---|---|
| 1 | `^([0-9])十([0-9])$` | `$1$2` | 2十3 → 23 |
| 2 | `^十([0-9])$` | `1$1` | 十2 → 12 |
| 3 | `^十$` | `10` | 十 → 10 |
| 4 | `(?<=^[0-9])十$` | `0` | 2十 → 20 |

## 2. ショートカットの設定

1. 編集画面下部の「ⓘ」（詳細）を開く。
2. 名前が **配達メッセージ** になっていることを確認（Siri はこの名前で起動する）。
3. 初回実行時に「ファイルへのアクセスを許可しますか」と表示されたら **常に許可** を選ぶ。Siri から初回実行すると許可画面が出て止まることがあるため、**最初は必ずショートカットアプリから1回実行**する。
4. 設定 → Siri → 「ロック中にSiriを許可」の状態をメモしておく（ロック中の動作をテスト T-21 で確認）。

## 3. データの更新方法（MVP）

1. PC（または Codex）で `data/messages.json` を編集し、`revision` を +1、`updatedAt` を更新する。
2. `python3 tools/haitatsu.py validate data/messages.json` で **エラー 0 件** を確認する。
3. 0-1 の方法で iPhone の同じ場所に上書き保存する。

> MVP ではショートカットからデータを書き換えない。追加・編集・削除は第2段階で実装する。
