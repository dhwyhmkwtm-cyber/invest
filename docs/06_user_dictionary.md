# 06. 配達用定型文とユーザ辞書の一括登録

`data/messages.json`（本番データ・32件）の一覧。同じデータから次の2つを作る。

- **ショートカット「配達メッセージ」**: 番号・キーワード・別名で呼び出す
- **ユーザ辞書**（iPhone・Mac共通）: 「よみ」を打つと本文が変換候補に出る

## 1. Mac で一括登録する

前提: Mac と iPhone が**同じ Apple ID** で、iCloud の同期がオンになっていること。

1. Mac でこのリポジトリの `dist/user_dictionary.plist` を用意する（データを変えた場合は下記コマンドで作り直す）。
2. Appleメニュー → **システム設定** → **キーボード** → 「テキスト入力」の **ユーザ辞書…**（表示が「テキストの置換…」の場合あり）を開く。
3. **取り込む前に** 一覧を全部選択（⌘A）してデスクトップへドラッグし、今の登録内容をバックアップしておく。
4. `user_dictionary.plist` をユーザ辞書の一覧へ**ドラッグ＆ドロップ**する。
5. iPhone の「設定 → 一般 → キーボード → ユーザ辞書」に反映されるまで待つ（数分〜数時間かかることがある）。

> **同じ「よみ」がすでに登録されている場合**（例: 手で登録済みの「k」「と」）、取り込み後に二重になることがある。手で登録した古い方を先に削除するか、取り込み後に重複を削除する。

```sh
python3 tools/haitatsu.py validate data/messages.json
python3 tools/haitatsu.py export-plist data/messages.json dist/user_dictionary.plist
```

## 2. iPhone で1件ずつ登録する

設定 → 一般 → キーボード → ユーザ辞書 → 「＋」。「単語」に本文、「よみ」に下表の よみ を入れる。

## 4. よみの付け方

- 1〜2文字のよみ（`k`、`と`、`あん`）は速いが、普段の入力でも候補に出る。気になる場合は長いよみに変える。
- よみは**ひらがな・英小文字・数字のみ**（検証ツールで確認）。同じよみの重複はエラーにしている。
- 「受け渡し暗証番号」は、配達完了に暗証番号の入力が必要な注文で、置き配を頼まれた場合に使う。「オートロック暗証番号」（11番）とは別。
- 待つ時間・置き配してよいかの扱いは配達アプリの案内が優先。実際の対応はアプリの指示に従う。
